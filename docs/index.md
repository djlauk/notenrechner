# notenrechner

Ein kleines Kommandozeilen-Tool, das Punkte in eine Note der Schweizer Skala (1–6) umrechnet.

```text
> notenrechner 42 --max 50
5.2
```

Diese Seite wird bei jedem Push auf `main` **automatisch** von einer GitHub Action gebaut
und auf GitHub Pages veröffentlicht.
